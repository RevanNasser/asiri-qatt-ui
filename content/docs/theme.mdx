# السمة

<p className="lead">ألوان قَطّ تستلهم أصباغ عسير على أرضية من الجصّ الأبيض. يمكنكم ضبط كل لون من متغيرات CSS، في الوضعين الفاتح والداكن.</p>

> قيم الألوان تقريبية من تصميم المشروع؛ تستحضر الأصباغ ولا تدّعي مطابقتها.

## الأصباغ

تُستخدم أسماء الأصباغ بوصفها تسميات لونية. اللون الأزرق خاصةً لا يثبت مصدره التقليدي بين المصادر، لذلك لا تنسب هذه السمة مصدراً له.

| الرمز | الاستخدام |
| --- | --- |
| `--qatt-jiss` | أرضية الجصّ |
| `--qatt-red` | الأحمر |
| `--qatt-yellow` | الأصفر |
| `--qatt-black` | الأسود |
| `--qatt-blue` | الأزرق |
| `--qatt-green` | الأخضر للزخرفة |

## متغيرات CSS

```css
:root {
  --qatt-jiss: oklch(0.97 0.012 88);
  --qatt-red: oklch(0.48 0.16 29);
  --qatt-yellow: oklch(0.76 0.15 83);
  --qatt-ink: oklch(0.22 0.02 64);
}
```

تستعمل النقوش الخانات `--qatt-slot-1` إلى `--qatt-slot-4`، لذلك يمكن تغيير ألوانها من غير تعديل الرسم نفسه. اجعلوا النص على خلفية ذات تباين كافٍ؛ الأخضر هنا للزخرفة فقط.

## الخطوط الطباعية

يستخدم موقع التوثيق خط ثمانية للنص والعناوين، وIBM Plex Mono للشيفرة. لا تدخل ملفات خط ثمانية في سجلّ المكوّنات ولا يعيد المشروع توزيعها؛ حمّلوها من مصدرها الرسمي إذا أردتم التجربة نفسها. أمّا السمة المثبّتة من السجل فتبقى بخطوطها المفتوحة المصدر. ثبّتوا السمة قبل أي مكوّن:

<InstallCommand item="qatt-theme" />

في الوضع الداكن يكون العرض تفسيراً رقمياً للمشروع؛ القط العسيري يُرسم على أرضية الجصّ الأبيض.
