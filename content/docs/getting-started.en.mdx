Welcome. Qatt is a shadcn/ui-compatible registry: not a package you install and forget, but code added to your project that you own. Install the theme first, then add any components and blocks you like.

Requirements: a project set up with shadcn/ui and Tailwind CSS.

Version 1 supports the base-nova style (built on Base UI) only. Radix support may come in a later release.

<Callout type="warn">
Heads-up: restyled components replace their files in <code dir="ltr">components/ui/</code>. Commit your changes to git before installing.
</Callout>

<Steps>
<Step>

### Set up the <bdi dir="ltr">@qatt</bdi> registry

Add the Qatt registry to <code dir="ltr">components.json</code> to use the short <code dir="ltr">@qatt/…</code> name instead of the full URL. Full URLs work either way.

```json title="components.json"
{
  "registries": {
    "@qatt": "https://asiri-qatt.rifan.xyz/r/{name}.json"
  }
}
```

</Step>
