## Usage

```tsx
import { Breadcrumb } from "@/components/ui/breadcrumb"

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">…</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>…</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Direction notes

The chevron flips to point left in Arabic. The slash does not flip and reads oddly in RTL, so we recommend chevron or khatmah for Arabic.

## Accessible

The nav is labelled “Breadcrumb”, and the current page carries aria-current="page".
