## Usage

```tsx
import { Tooltip } from "@/components/ui/tooltip"

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button />}>…</TooltipTrigger>
    <TooltipContent>…</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## Direction notes

inline-start and inline-end resolve to right or left from the page direction.

## Accessible

For supplementary information only; never put essential content in a tooltip. Triggers must be keyboard-focusable; the open delay is 300 ms.
