## Usage

```tsx
import { Avatar } from "@/components/ui/avatar"

<Avatar ring>
  <AvatarImage src="…" alt="…" />
  <AvatarFallback tone="red">…</AvatarFallback>
</Avatar>
```

## Direction notes

When avatars overlap, use the logical margin -ms-2 instead of -space-x-2.

## Accessible

Give AvatarImage alt text. Fallback contrast is checked per tone: yellow and orange use charcoal text.
