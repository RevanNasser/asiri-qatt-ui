زخرفةٌ صغيرة في ركن البطاقة أو الإطار، هيئتها الافتراضية «الختمة»: المربّع الذي تُختم به الأشرطة. ويروي أحد المصادر أنّ الختمة كانت الموضع الذي تُبدي فيه القطّاطة لمستها الخاصة.

## الاستخدام

ضعوه داخل عنصرٍ له `position: relative`، واختاروا الركن بالخاصية `position`. ولأركانٍ أربعة كرّروه أربع مرات.

```tsx
import { QattCorner } from "@/components/ui/qatt-corner"

<div className="relative">
  <QattCorner position="start-start" />
  …
</div>
```

## ملاحظات الاتجاه

الأركان منطقية: `start-start` هو الركن العلوي الأيمن في العربية، والعلوي الأيسر في الإنجليزية.

## سهولة الوصول

زخرفةٌ خالصة مخفيّة عن التقنيات المساعدة ولا تستقبل النقر. تأكّدوا ألّا تغطّي نصًّا أو زرًّا.
