## Usage

```tsx
import { Dialog } from "@/components/ui/dialog"

<Dialog>
  <DialogTrigger render={<Button />}>…</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>…</DialogTitle>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

## Direction notes

The close button sits at inline-end. The footer keeps shadcn's order (cancel, then confirm) aligned to the end, so confirm lands on the left in Arabic, at the end of the reading path.

## Accessible

DialogTitle is required. Initial focus goes to the first field, or to the safe action when confirming something that cannot be undone.
