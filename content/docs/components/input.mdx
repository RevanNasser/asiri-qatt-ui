## ملاحظات الاتجاه

الاتجاه موروثٌ من الصفحة. اجعلوا `dir="ltr"` لحقول البريد الإلكتروني والروابط وكلمات المرور، ومحاذاة النص الإرشادي منطقية.

## سهولة الوصول

ضعوا تسميةً ظاهرةً دائمًا، ولا تكتفوا بالنص الإرشادي. ولحالة الخطأ استعملوا `aria-invalid` مع نصّ خطأٍ مربوطٍ عبر `aria-describedby`.
