## Usage

```tsx
import { Button } from "@/components/ui/button"

<Button variant="qatt">…</Button>
<Button variant="painted" tone="blue">…</Button>
```

## Direction notes

Place icons with data-icon="inline-start" or "inline-end"; arrow icons flip automatically in RTL.

## Accessible

Solid, visible focus outline; loading is announced with aria-busy plus a spinner; minimum target 24px. Every painted tone keeps labels at 4.5:1 or more at rest and on hover, in light and dark mode.
