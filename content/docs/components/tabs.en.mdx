## Usage

```tsx
import { Tabs } from "@/components/ui/tabs"

<Tabs defaultValue="a">
  <TabsList variant="qatt">
    <TabsTrigger value="a">…</TabsTrigger>
  </TabsList>
  <TabsContent value="a">…</TabsContent>
</Tabs>
```

## Direction notes

Base UI maps arrow keys to the direction, so in Arabic the right arrow moves to the previous tab. The active indicator is positioned from inline-start.

## Accessible

Focus moves between tabs with the arrow keys (roving tabindex); the focus outline is drawn inside the list so it is not clipped.
