## Usage

```tsx
import { Pagination } from "@/components/ui/pagination"

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## Direction notes

Previous sits at inline-start (the right in Arabic) with its chevron pointing right. Digits are Western and tabular.

## Accessible

The nav is labelled “Pagination”; the active page carries aria-current="page"; icon-only buttons carry an aria-label.
