## Usage

```tsx
import { Accordion } from "@/components/ui/accordion"

<Accordion variant="qatt">
  <AccordionItem value="a">
    <AccordionTrigger>…</AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Direction notes

Trigger text starts at inline-start with the chevron at inline-end. The chevron points down and rotates 180° when open, so it is not flipped in RTL.

## Accessible

Base UI renders triggers inside headings, and each trigger carries aria-expanded.
