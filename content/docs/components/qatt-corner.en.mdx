A small ornament for the corner of a card or frame. Its default form is the khatmah, the square that closes a band. One source relates that the khatmah was where the painter showed her own touch.

<InstallCommand item="qatt-corner" />

## Usage

Place it inside an element with position: relative and choose the corner with position. Repeat it four times for all four corners.

```tsx
import { QattCorner } from "@/components/ui/qatt-corner"

<div className="relative">
  <QattCorner position="start-start" />
  …
</div>
```

## Direction notes

Corners are logical: start-start is top-right in Arabic and top-left in English.

## Accessible

Pure decoration, hidden from assistive technology and not clickable. Make sure it never covers text or a button.
