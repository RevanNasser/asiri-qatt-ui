## Usage

```tsx
import { Card } from "@/components/ui/card"

<Card variant="painted">
  <CardHeader>
    <CardTitle>…</CardTitle>
  </CardHeader>
  <CardContent>…</CardContent>
</Card>
```

## Direction notes

The ornament strip is symmetric and its caps use logical sides, so nothing needs flipping.

## Accessible

The card stays a plain div. For a clickable card, use one inner link stretched with after:absolute after:inset-0, not a link wrapping the whole card.
