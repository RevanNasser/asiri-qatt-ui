## Usage

```tsx
import { Select } from "@/components/ui/select"

<Select items={items}>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>…</SelectContent>
</Select>
```

## Direction notes

The popup aligns to the trigger's inline-start, and the check mark sits at inline-start.

## Accessible

Base UI typeahead jumps to an option by its first letters, Arabic letters included.
