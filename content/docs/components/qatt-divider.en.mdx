A band that separates two sections, the way the qatt divides a majlis wall. Some documenters say the art takes its name from this belt, drawn crosswise to split the wall in two.

<ComponentPreview name="qatt-divider-demo" />

## Installation

<InstallCommand item="qatt-divider" />

## Usage

Use it between major page sections; pass label to centre a short title between two bands. For small breaks inside cards and lists, separator is enough.

```tsx
import { QattDivider } from "@/components/ui/qatt-divider"

<QattDivider />
<QattDivider motif="rukun" thickness="md" label="…" />
```

## Direction notes

The band is symmetric, the label stays centred in both directions, and the reveal starts at inline-start.

## Accessible

Decorative by default. If it separates content that differs in meaning, set decorative=\{false\} so it is announced as a separator with aria-orientation. The label is ordinary readable text.
