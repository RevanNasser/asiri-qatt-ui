## Usage

```tsx
import { Sheet } from "@/components/ui/sheet"

<Sheet>
  <SheetTrigger render={<Button />}>…</SheetTrigger>
  <SheetContent side="start">…</SheetContent>
</Sheet>
```

## Direction notes

start and end resolve to a physical side from the page direction via useDirection(), and the slide animation follows it.

## Accessible

Same as Dialog: a title is required, and focus stays inside the sheet until it closes.
