حيّاكم. «قَطّ» سجلٌّ متوافق مع shadcn/ui: لا حزمة تُثبَّت ثم تُنسى، بل شيفرةٌ تُضاف إلى مشروعكم فتملكونها. ابدأوا بتثبيت السمة، ثم أضيفوا ما شئتم من المكوّنات والكتل.

المتطلبات: مشروعٌ مهيّأ بـ shadcn/ui وTailwind CSS.

يدعم الإصدار الأول نمط <bdi>base-nova</bdi> المبنيّ على <bdi>Base UI</bdi> فقط. وقد يُضاف دعم <bdi>Radix</bdi> في إصدارٍ لاحق.

<Callout type="warn">
تنبيه: المكوّنات المُعاد تصميمها تحلّ محلّ ملفاتها في <bdi dir="ltr">components/ui/</bdi>. احفظوا تعديلاتكم في git قبل التثبيت.
</Callout>

<Steps>
<Step>

### إعداد النطاق <bdi dir="ltr">@qatt</bdi>

أضيفوا سجلّ قَطّ إلى <bdi dir="ltr">components.json</bdi> لتكتبوا الأوامر بالاسم المختصر <bdi dir="ltr">@qatt/…</bdi> بدل الرابط الكامل. والروابط الكاملة تعمل في الحالتين.

```json title="components.json"
{
  "registries": {
    "@qatt": "https://asiri-qatt.rifan.xyz/r/{name}.json"
  }
}
```

</Step>
<Step>

### ثبِّتوا سمة قَطّ

<InstallCommand item="qatt-theme" />

</Step>
<Step>

### اضبطوا اتجاه الصفحة بإضافة `dir="rtl"` و`lang="ar"` إلى وسم `html`

```tsx title="app/layout.tsx"
<html lang="ar" dir="rtl">
```

</Step>
<Step>

### أضيفوا أول مكوّن

<InstallCommand item="qatt-divider" />

</Step>
</Steps>

هذا كلّ شيء. على الرحب والسعة.
