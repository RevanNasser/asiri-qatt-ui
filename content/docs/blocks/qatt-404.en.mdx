## Usage

Keep the text short and kind, and never blame the visitor. Offer at least two ways out: home and search.

```tsx
import { Qatt404 } from "@/components/qatt-404"

<Qatt404 title="…" homeLabel="…" />
```

## Direction notes

The 404 code is isolated in bdi and uses Western digits in both directions.

## Accessible

The h1 is the sentence, not the number, so screen readers state the problem at once. The code and frame are decorative.
