## Usage

Arrange links in three or four columns of no more than five links each. If you use Qatt ornaments, keep the inspiration note in heritageNote.

```tsx
import { QattFooter } from "@/components/qatt-footer"

<QattFooter brand="…" columns={[{ title: "…", links: [{ label: "…", href: "#" }] }]} />
```

## Direction notes

The brand sits at inline-start with the columns after it. The external-link arrow does not flip.

## Accessible

The footer is a landmark and column titles are real headings. Links that open a new tab say so to screen readers.
