شهاداتٌ ممّن جرّبوا منتجكم، في شبكةٍ من البطاقات أو اقتباسٍ واحد كبير، بعلامة اقتباسٍ زخرفية تحفّها «سنكرولي».

<Callout>
المحتوى هنا افتراضيٌّ للعرض: الأسماء والأرقام والأسعار والآراء مختلَقة، فاستبدلوها بمحتواكم.
</Callout>

## الاستخدام

الأسماء والآراء في المثال مختلَقة للعرض، فلا تنشروها كما هي، واستعملوا آراءً حقيقية بإذن أصحابها. واكتبوا الاقتباس العربي بين علامتَي التنصيص «…».

```tsx
import { QattTestimonials } from "@/components/qatt-testimonials"

<QattTestimonials title="…" items={[{ quote: "«…»", name: "…" }]} />
```

## ملاحظات الاتجاه

علامة الاقتباس الزخرفية في بداية السطر، والاقتباسات الإنجليزية داخل النص العربي تُعزل بـ `bdi`.

## سهولة الوصول

كلّ شهادةٍ `figure` فيها `blockquote` و`figcaption`. وعلامة الاقتباس الكبيرة زخرفية، وللصور الرمزية نصٌّ بديل.
