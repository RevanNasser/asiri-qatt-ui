## Usage

Place it at the end of the page before the footer, with a short title, one clear call to action and a secondary button if needed.

```tsx
import { QattCta } from "@/components/qatt-cta"

<QattCta title="…" primary={{ label: "…", href: "#" }} />
```

## Direction notes

Buttons follow reading order: primary first, at inline-start.

## Accessible

Text on red or ink bands is gypsum and passes contrast; the primary button switches to painted yellow to stay prominent.
