شبكةٌ من البطاقات المرسومة تعرض مزايا منتجكم، لكلّ ميزةٍ أيقونةٌ في مربّعٍ ملوّن على هيئة «الختمة»، وخلفها «الشبكة» بخفوتٍ شديد.

</Callout>

## الاستخدام

ثلاثة أعمدةٍ تناسب ستّ مزايا، وعمودان يناسبان أربعًا. اجعلوا عنوان الميزة كلمتين أو ثلاثًا، ووصفها جملةً واحدة. وإن أعطيتم الميزة `href` صارت البطاقة كلّها قابلةً للنقر عبر رابطٍ واحد في داخلها.

```tsx
import { QattFeatureGrid } from "@/components/qatt-feature-grid"

<QattFeatureGrid title="…" features={[{ title: "…", body: "…" }]} />
```

## ملاحظات الاتجاه

تُملأ الشبكة من بداية السطر، ولا تنقلب من الأيقونات إلا الاتجاهية.

## سهولة الوصول

عناوين المزايا `h3` تحت عنوان القسم، والأيقونات زخرفية. وفي البطاقة القابلة للنقر رابطٌ واحد اسمه عنوان الميزة.
