## Usage

The names and quotes in the demo are made up; do not publish them. Use real testimonials with permission. Wrap Arabic quotes in «…».

```tsx
import { QattTestimonials } from "@/components/qatt-testimonials"

<QattTestimonials title="…" items={[{ quote: "«…»", name: "…" }]} />
```

## Direction notes

The decorative quote mark sits at inline-start; English quotes inside Arabic text are isolated with bdi.

## Accessible

Each testimonial is a figure with blockquote and figcaption. The large quote mark is decorative; avatars have alt text.
