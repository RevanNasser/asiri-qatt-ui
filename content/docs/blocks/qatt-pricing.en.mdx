## Usage

Prices in the demo are samples. Pass period to show a monthly/yearly toggle. In Arabic the currency follows the number: 99 SAR.

```tsx
import { QattPricing } from "@/components/qatt-pricing"

<QattPricing title="…" plans={[{ name: "…", price: 99, features: ["…"], cta: { label: "…", href: "#" } }]} />
```

## Direction notes

Price and currency are isolated in bdi with tabular digits. Check marks in feature lists do not flip.

## Accessible

Plan names are headings; the recommended plan is marked by a text badge, not colour alone. Each button's accessible name includes the plan, e.g. “Choose the Growth plan”.
