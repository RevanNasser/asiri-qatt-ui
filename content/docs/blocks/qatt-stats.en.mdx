## Usage

The figures in the demo are samples; replace them with real ones. Western digits are the default; numerals="arab" shows Arabic-Indic digits for decorative contexts.

```tsx
import { QattStats } from "@/components/qatt-stats"

<QattStats stats={[{ value: 98, suffix: "%", label: "…" }]} />
```

## Direction notes

Each value is isolated in bdi so % and + stay in place. Write prefix and suffix as they read, e.g. 98%.

## Accessible

The final value is in the DOM from the start, so assistive technology reads it even with the count-up, and the count-up stops under reduced motion.
