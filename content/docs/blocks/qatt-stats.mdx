## الاستخدام

الأرقام في المثال افتراضية، فاستبدلوها بأرقامكم الحقيقية. وتُعرض بالأرقام الغربية افتراضيًا، ويمكن عرضها بالأرقام المشرقية عبر `numerals="arab"` في السياقات الزخرفية.

```tsx
import { QattStats } from "@/components/qatt-stats"

<QattStats stats={[{ value: 98, suffix: "%", label: "…" }]} />
```

## ملاحظات الاتجاه

كلّ قيمةٍ معزولةٌ داخل `bdi` فلا تضطرب علامة النسبة أو الزائد. واكتبوا البادئة واللاحقة كما تُقرآن، مثل «98%».

## سهولة الوصول

القيمة النهائية موجودةٌ في الصفحة من البداية، فتقرؤها التقنيات المساعدة حتى مع العدّ المتحرّك، والعدّ يتوقّف عند تفعيل تقليل الحركة.
