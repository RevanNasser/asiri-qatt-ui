## Usage

Pass onSubmit to receive email and password, and errors to show server errors. Arabic messages are ready; on a failed sign-in, never reveal which field was wrong.

```tsx
import { QattLogin } from "@/components/qatt-login"

<QattLogin onSubmit={async ({ email, password }) => { /* … */ }} forgotHref="/forgot" signUpHref="/sign-up" />
```

## Direction notes

Email and password inputs are left-to-right; their labels and error messages stay right-to-left.

## Accessible

Labels are always visible, each error is linked to its field with aria-describedby, and form-level errors are announced in a live region. The show-password button has aria-pressed and an accessible name; the submit button announces loading.
