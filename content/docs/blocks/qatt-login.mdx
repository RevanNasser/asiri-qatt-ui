نموذج دخولٍ مرحِّب: الحقول في بداية السطر، ولوحةٌ زخرفية من «سنكرولي» و«إطار القوس» في نهايته. وعلى الجوّال تختفي اللوحة ويعلو النموذجَ شريطٌ من «الركون».

## الاستخدام

مرّروا `onSubmit` لاستقبال البريد وكلمة المرور، و`errors` لعرض أخطاء الخادم. النصوص العربية جاهزة، وعند فشل الدخول لا تكشفوا أيّ الحقلين أخطأ.

```tsx
import { QattLogin } from "@/components/qatt-login"

<QattLogin onSubmit={async ({ email, password }) => { /* … */ }} forgotHref="/forgot" signUpHref="/sign-up" />
```

## ملاحظات الاتجاه

حقلا البريد وكلمة المرور من اليسار إلى اليمين، وتسمياتهما ورسائل أخطائهما من اليمين إلى اليسار.

## سهولة الوصول

التسميات ظاهرةٌ دائمًا، وكلّ خطأٍ مربوطٌ بحقله عبر `aria-describedby`، وخطأ النموذج العام يُعلَن في منطقةٍ حيّة. وزرّ إظهار كلمة المرور يحمل `aria-pressed` واسمًا مقروءًا، وزرّ الدخول يُعلن حالة التحميل.
