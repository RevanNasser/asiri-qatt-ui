صفحة خطأٍ لطيفة: الرمز 404 داخل «إطار القوس»، وعنوانٌ ووصفٌ موجز، وطريقٌ إلى الرئيسية والبحث، وصفٌّ من «المحاريب» عند القاعدة.

<Callout>
المحتوى هنا افتراضيٌّ للعرض: الأسماء والأرقام والأسعار والآراء مختلَقة، فاستبدلوها بمحتواكم.
</Callout>

## التثبيت

<InstallCommand item="qatt-404" />

## الاستخدام

اجعلوا النص قصيرًا وودودًا، ولا تلوموا الزائر. وأعطوه مخرجين على الأقل: الرئيسية والبحث.

```tsx
import { Qatt404 } from "@/components/qatt-404"

<Qatt404 title="…" homeLabel="…" />
```

## ملاحظات الاتجاه

الرمز 404 معزولٌ في `bdi` ويُكتب بالأرقام الغربية في الاتجاهين.

## سهولة الوصول

العنوان `h1` هو الجملة لا الرقم، فيعرف قارئ الشاشة المشكلة فورًا. والرمز والإطار زخرفيان.
