خطط الأسعار جنبًا إلى جنب، والخطة المقترحة في بطاقةٍ مؤطّرة تعلوها زخرفة «التعذيق» وشارةٌ تُبرزها.

</Callout>

## الاستخدام

الأسعار في المثال افتراضية. مرّروا `period` لإظهار مبدّلٍ بين الشهري والسنوي. واكتبوا العملة بعد الرقم كما في العربية: «99 ر.س».

```tsx
import { QattPricing } from "@/components/qatt-pricing"

<QattPricing title="…" plans={[{ name: "…", price: 99, features: ["…"], cta: { label: "…", href: "#" } }]} />
```

## ملاحظات الاتجاه

السعر والعملة معزولان في `bdi`، والأرقام بعرضٍ ثابت. وعلامات الصحّ في قائمة المزايا لا تنقلب.

## سهولة الوصول

اسم الخطة عنوان، والخطة المقترحة تُعرف بشارةٍ نصية لا باللون وحده. ولكلّ زرٍّ اسمٌ مقروء يذكر الخطة، مثل «اختر خطة النموّ».
