شريطٌ ختامي يدعو الزائر إلى الخطوة التالية، بلونٍ واحد وصفٍّ من زخارف «التعذيق».

<Callout>
المحتوى هنا افتراضيٌّ للعرض: الأسماء والأرقام والأسعار والآراء مختلَقة، فاستبدلوها بمحتواكم.
</Callout>

## الاستخدام

ضعوه في آخر الصفحة قبل التذييل، بعنوانٍ قصير ودعوةٍ واحدة واضحة، وزرٍّ ثانوي إن لزم.

```tsx
import { QattCta } from "@/components/qatt-cta"

<QattCta title="…" primary={{ label: "…", href: "#" }} />
```

## ملاحظات الاتجاه

الأزرار تتبع ترتيب القراءة: الرئيسي أولًا في بداية السطر.

## سهولة الوصول

النص على الشريط الأحمر أو الداكن بلون الجصّ ويتجاوز نسبة التباين المطلوبة، والزرّ الرئيسي يصير بالطلاء الأصفر ليبقى بارزًا.
