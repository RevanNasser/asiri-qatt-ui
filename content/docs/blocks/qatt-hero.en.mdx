## Usage

Pass align="start" with media for a two-column hero: text at inline-start and the media in an arch frame at inline-end on large screens. Keep the subtitle to about 60 characters per line.

```tsx
import { QattHero } from "@/components/qatt-hero"

<QattHero
  title="…"
  subtitle="…"
  primaryCta={{ label: "…", href: "/docs" }}
/>
```

## Direction notes

Columns follow the page direction, the primary button's arrow flips, and the install command is always shown left-to-right.

## Accessible

The title is the page's only h1. The animation is opt-in and stops under reduced motion, and the copy button announces “Copied”.
